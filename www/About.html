This map displays a snapshot of the most recent survey of each Northeast Temperate Network forest health monitoring plot. Each plot was sampled between 2023 and 2026, and each circle indicates the location of a plot. Clicking on the circle will produce a popup with basic data summaries from the most recent survey of each plot, along with photos taken on the day the plot was last sampled.

More information can be found on NETN Forest Monitoring website, and the latest NETN/MIDN Forest Monitoring Protocol documents.
